HOW IT WORKS

Three steps.
One calmer video.

SkipTube runs in your browser and asks SponsorBlock for existing community segment data.

  1. 01

    Open a YouTube video

    SkipTube reads the current video ID and requests enabled segment categories.

  2. 02

    Choose your preferences

    Pick which segment categories to skip, set channel and video whitelists, and choose confirmation behavior.

  3. 03

    Watch your way

    When playback enters a known enabled segment, SkipTube seeks to its submitted end time.

INSTALLATION

Choose your browser.

The Chrome Web Store listing is not published yet. For now, install the unpacked project locally.

◉

Google Chrome

Developer installation
  1. Download or clone the SkipTube repository after its public URL is configured.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the folder containing manifest.json.
  5. Open a YouTube video and pin SkipTube from the extensions menu.
♢

Brave

Developer installation
  1. Download or clone the SkipTube repository after its public URL is configured.
  2. Open brave://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the folder containing manifest.json.
  5. Open a YouTube video and pin SkipTube.

After Chrome Web Store publication, the site can link to the listing for Chrome and Brave. No store install button is shown before publication.

COMMON QUESTIONS

Good to know.

Does SkipTube detect every sponsor or self-promotion?

No. It uses community-submitted SponsorBlock segments. If no segment exists for a video, SkipTube cannot infer timestamps or create a segment automatically.

Does it send my watch history to SkipTube?

SkipTube has no server. After you agree in the popup, it sends the current video ID and enabled categories to SponsorBlock to retrieve segment data. See the Privacy Policy for the full details.

Are submissions automatic?

No. You mark the start and end, choose a category, review the details, and confirm. Confirmed submissions are public on SponsorBlock.

Does it work in Brave?

The extension targets Chrome's Manifest V3 and is designed for Brave's Chromium compatibility. Brave-specific behavior still needs release-candidate manual testing before distribution claims.

How do I get support or contribute?

The repository and issue links will be enabled after the public GitHub repository is created. Until then, this local release preparation does not invent a contact address.
