Privacy Policy

Last updated: November 17, 2026

SkipTube is an independent browser extension created by Prince Kushwaha for skipping YouTube video segments using community-submitted data. It is not affiliated with YouTube, Google, or SponsorBlock. This policy explains the extension's actual storage and network behavior.

Information stored in your browser

SkipTube stores the following in the browser's extension storage on your device/profile:

  • Preferences such as enabled state, segment categories, auto-skip and confirmation choices, notification duration, developer diagnostics setting, and your first-use consent choice.
  • Channel and video whitelist entries.
  • A segment response cache. Non-empty responses expire after 30 minutes; empty responses expire after 5 minutes.
  • Aggregate skip count and estimated seconds saved.
  • A randomly generated local SponsorBlock submission ID. It is not a login credential and SkipTube does not derive a public ID from it.
  • Temporary per-tab status in session storage, cleared when tabs close or the browser session storage is cleared.

These values are not sent to a SkipTube server. SkipTube has no backend. Local data remains until you clear the extension's data or remove the extension; resetting preferences does not erase skip totals.

Consent before segment lookup

On first use, the extension popup displays a notice describing the segment lookup request and asks you to select “Agree and continue.” SkipTube does not request segment data until you take that action. Your consent choice is stored locally as an extension preference. You can stop lookups at any time by switching SkipTube off; clearing the extension's stored data resets consent.

Requests to SponsorBlock

After consent, when you play a YouTube video while SkipTube is enabled, SkipTube requests segment information from SponsorBlock's API. The request includes the current video ID, enabled categories, and requested action types. SponsorBlock therefore receives the video identifier and selected category query, along with ordinary network request metadata such as your IP address. SponsorBlock's own privacy practices apply to information it receives.

SkipTube does not send the channel ID to SponsorBlock. It reads the channel link locally only to apply your channel whitelist.

Public segment submissions

A segment is submitted only after you mark its start and end, choose a category, review a confirmation dialog, and confirm. The request includes the video ID, start and end timestamps, category, video duration, locally stored random submission ID, and SkipTube client identifier. SponsorBlock may publish accepted submissions and process requests under its own rules and privacy practices. Never submit information you do not want to contribute publicly.

Skip statistics

Skip count and estimated seconds saved are stored locally. SkipTube does not upload these statistics or associate them with an account.

Developer diagnostics

Optional diagnostics are disabled by default. When enabled, SkipTube writes the current video ID, requested categories, segment counts by category, Self-promotion filtering counts, and skipped segment counts to the local YouTube page console. It does not transmit these diagnostic logs.

Permissions and page access

  • Storage: saves preferences, cache, statistics, a local submission ID, and temporary session state.
  • YouTube host access/content script: reads the current video ID, player time/duration, and channel link for segment lookup, playback seeking, marker display, whitelisting, and user-initiated submission.
  • SponsorBlock host access: fetches community segments and sends a submission only after your confirmation.

SkipTube does not request access to unrelated sites, use analytics, load remote executable code, or include advertising or tracking scripts.

Website hosting

The project website is a static GitHub Pages site and contains no SkipTube analytics or external advertising scripts. GitHub operates the hosting service and may process ordinary website request metadata, including IP addresses, under GitHub's Privacy Statement.

Children and accounts

SkipTube has no account system, age gate, or child-directed data collection feature. YouTube and SponsorBlock remain subject to their own terms and policies.

Policy changes and contact

If data handling changes, this policy and the extension disclosures must be updated before releasing that behavior. A public support or security reporting link will be configured after the repository is created; no contact address is published here.

Chrome Web Store Limited Use

SkipTube's use and transfer of information received through its extension permissions is limited to providing the disclosed single purpose and user-facing features. Information is shared with SponsorBlock only as necessary to retrieve community segments or to process a segment submission you explicitly review and confirm. SkipTube does not use or transfer this information for advertising, sale, or unrelated purposes and does not permit human review of it.

See the SkipTube home page or the public source repository after its URL is configured.
