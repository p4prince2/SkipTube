# SkipTube 1.0.0

Initial public release candidate for Chrome Manifest V3 and Chromium-based Brave.

## Included

- Automatic skipping of community-submitted SponsorBlock segments across eight categories, including Self-promotion.
- Per-category controls, progress-bar markers, channel/video whitelists, local skip statistics, and cached segment responses.
- YouTube single-page navigation and popup-to-existing-tab settings synchronization.
- First-use disclosure and affirmative consent before SponsorBlock segment lookups.
- Segment marking and explicit confirmation before public SponsorBlock submissions.
- Local privacy diagnostics, disabled by default.

## Release status

Prepared locally. This release has not been published to GitHub or the Chrome Web Store. Browser QA, real product screenshots, security reporting route setup, and verification of bundled asset ownership remain outstanding.

## Validation

The project's unit tests, static checks, ZIP integrity checks, extracted-file checks, and SHA-256 checksum are run by the local release process. Live Chrome and Brave checks are recorded separately in the release report and are not implied by these notes.
