## Create and configure

1. Create a public GitHub repository named `SkipTube` under the chosen account. Do not create an additional README, license, or `.gitignore`.
2. Confirm the attribution, icon provenance, and contributor rights before adding the license and source to a public repository.
3. Configure a private vulnerability reporting route in the repository's Security settings. Until this works, keep the security policy's explicit no-private-route warning.
4. Configure the default branch, repository description, topics, and the published website URL above.
5. After reviewing and approving the files, add the remote URL using your actual account. This project does not assume or embed a GitHub username.
6. Create and push the first commit only after separate owner approval. Tag the reviewed release as `v1.0.0` after release validation.
