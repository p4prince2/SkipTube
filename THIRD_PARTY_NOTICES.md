# Third-party code and asset review

## Dependencies

`package.json` declares no npm runtime or development dependencies. The extension uses browser-provided Chrome APIs and requests community segment data from SponsorBlock's public API; the API is an external service, not bundled code.

## Bundled visual assets

The production ZIP contains `icons/icon16.png`, `icons/icon48.png`, and `icons/icon128.png`. The website's `docs/favicon.png` is byte-identical to `icon48.png`. The project owner reports that the SkipTube icons were generated by Codex specifically for this project. Visual inspection shows a gradient tile with a simple play-shaped mark; no recognizable third-party logo or copied artwork is apparent. These observations do not independently establish copyright ownership or legal status. The repository does not include the generation record. Do not treat this notice as a legal opinion or apply the project's MIT terms to any third-party asset without confirming its license.

No third-party JavaScript library, font, remotely hosted script, analytics SDK, or copied product screenshot is bundled.
