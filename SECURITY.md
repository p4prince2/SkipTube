# Security Policy

## Supported version

Security reports should identify the affected SkipTube release or commit. The current workspace is pre-publication and has no published release channel.

## Reporting a vulnerability

Do not include exploit details, credentials, or private user data in a public issue. Before public launch, the maintainer should enable GitHub private vulnerability reporting or configure another private reporting route. Once the actual repository owner is known, the intended GitHub route is `https://github.com/<owner>/SkipTube/security/advisories/new`; this is a placeholder, not a live contact link. No email address or GitHub username is assumed.

Until a private route is configured, there is no verified private reporting channel. Public release should wait until one is set up and tested.

## Scope

Relevant reports include extension code execution, unintended data transmission, permission misuse, unsafe submission behavior, or a vulnerability in the website/release package. Include reproducible steps and impact, avoiding real user data.
