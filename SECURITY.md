# Security Policy

## Supported version

Security reports should identify the affected SkipTube commit or release. The source repository is public, but SkipTube has not been released through the Chrome Web Store.

## Reporting a vulnerability

Do not include exploit details, credentials, or private user data in a public issue. GitHub private vulnerability reporting has not been confirmed as enabled or tested. The intended route is `https://github.com/p4prince2/SkipTube/security/advisories/new`, but it must not be treated as an active private channel until the owner enables the feature and verifies that it accepts private reports.

Until a private route is configured and tested, there is no verified private reporting channel. Chrome Web Store release should wait until one is set up and tested.

## Scope

Relevant reports include extension code execution, unintended data transmission, permission misuse, unsafe submission behavior, or a vulnerability in the website/release package. Include reproducible steps and impact, avoiding real user data.
